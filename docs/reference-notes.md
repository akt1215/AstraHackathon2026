# Visual reference: Anshu's Afterlight browser demo

Inspected September 10, 2026, in Chrome through the public X page. This records a visual reference and attributed creator claims, not an independently reproduced benchmark.

## What was directly visible

Reference: <https://x.com/anshuc/status/2096008083826725132>

The inline video depicts an isometric ruined courtyard with dense stone architecture, broken edges and debris, vegetation, warm practical lights, a reflective-looking ground surface, atmospheric haze, moving characters, and a restrained dark HUD. Its materials and lighting suggest physical depth while the silhouettes remain deliberately stylized. It is a cinematic stylized scene, not evidence of photorealistic human rendering. The public video played inline; selecting its separate media view opened a login prompt, which was dismissed.

The creator describes the first result as occurring in 45 minutes. That timing, quota use, hardware, frame rate, implementation completeness, and any claimed one-shot process were not independently verified. No playable build or source code was inspected in this review.

## Creator's described workflow

Process reply: <https://x.com/anshuc/status/2096008086901113339>

The expanded reply describes connecting Codex to Blender MCP, generating concept-art targets through image generation, comparing actual in-game screenshots to those targets, using Blender to model the scene's assets, and generating mesh textures. It names high reasoning effort and a 60 FPS target.

Exact short excerpt describing the requested art direction:

> sad but beautiful dystopian theme with a voxel-ish art style, and lighting that feels real and physical.

## Scope clarification

Clarification reply: <https://x.com/anshuc/status/2096170387126042973>

Exact short excerpts:

> It’s three.js in browser, no other dependencies and no external assets

> I asked for a small graphics demo to start

The remainder of that clarification distinguishes the initial visual prototype from gameplay development that was still in progress. A later linked post describes eight hours of subsequent graphics and gameplay work: <https://x.com/anshuc/status/2096584624432374151>.

## Implication for the current life-sim proof

This reference supports targeting much richer lighting, materials, geometry, framing, and atmosphere within a browser. It does not establish that an engine switch is required, or that a polished life simulation with detailed characters and interactions can be completed to the same bar in 45 minutes. Generated concept images and material textures may guide or furnish the real scene; rendered screenshots, controllable movement, persistent state, and measured runtime performance remain the acceptance evidence.
